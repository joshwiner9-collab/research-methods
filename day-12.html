Your formula sheet

The exam is open-materials, so this is what your printed notes should hold.

Centre
Median seat (n + 1)/2 · mean = Σx·f / n
Grouped median = L + ((n/2 − F)/f) × width
Spread
s² = Σ(x − x̄)² / n = Σx²/n − x̄²
y = a + bx → s × |b|, s² × b²
Position
z = (x − x̄)/s · x = x̄ + z·s · CV = s / x̄
Chebyshev: at least 1 − 1/k² within k·s
One-sample t
t = (x̄ − μ₀) / (s/√n)
df = n − 1
Two-sample t
t = (x̄₁ − x̄₂) / √(s₁²/n₁ + s₂²/n₂)
df = n₁ + n₂ − 2
Correlation
cov = Σdₓdᵧ / n · r = cov / (sₓsᵧ)
var = w²var x + (1−w)²var y + 2w(1−w)cov
Regression
β̂₁ = Σdₓdᵧ / Σdₓ² · β̂₀ = ȳ − β̂₁x̄
R² = r² · t = (b − value)/SE, df = n − 2
