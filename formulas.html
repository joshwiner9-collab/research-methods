Every formula, on one page

Nothing here has to be memorised. What you practise is knowing which one applies, and why. Print this page and bring it.

Lesson 1 · Variables

Nominal → mode. Ordinal → mode, median. Quantitative → mode, median, mean.

Which centres each type allows.

Parameter = the population truth. Statistic = its sample estimate.

Anything computed from a sample is a statistic.

Lesson 2 · Tables

p(x) = f(x) / n

Relative frequency; compares samples of different size.

At most x = F(x). At least x = n − F(one below x).

Ordered values only.

ℓ = upper − lower · d = f / ℓ · d% = p / ℓ

Histogram heights are d; area = f; total area = n.

Lesson 3 · Centre

Median at seat (n + 1)/2 of sorted data

Even n: average the two middle seats.

Mean from a table = Σx·f / n

Discrete table.

Combined mean = (n₁x̄₁ + n₂x̄₂) / (n₁ + n₂)

Groups of different size.

Grouped median = L + ((n/2 − F before) / f) × width

The class where F first reaches n/2.

Grouped mode = midpoint of the highest-density class

Grouped data.

Σa = n·a · Σax = aΣx · Σ(x + y) = Σx + Σy; Σxy ≠ ΣxΣy

Expand first, then sum.

Harmonic: n / Σ(1/x) · geometric: (x₁x₂…xₙ)^(1/n)

Speeds over equal distances; compounding growth.

Lesson 4 · Spread

Dial = n·z/100 → first value whose F reaches it

Percentiles on a frequency table.

Q1 at (n + 1)/4, Q3 at 3(n + 1)/4 · IQR = Q3 − Q1

Raw sorted data.

s² = Σ(x − x̄)² / n = Σx²/n − x̄² · s = √s²

Divide by n, always.

Percentile = L + ((p·n − F before) / f) × width

Grouped data.

y = a + bx → ȳ = a + bx̄, s_y = |b|s, s²_y = b²s²

Adding or scaling every value.

Symmetric if Q3 − Q2 = Q2 − Q1

Wider upper gap: right skew.

Lesson 5 · Relative position

z = (x − x̄) / s · x = x̄ + z·s

Place one value in its own crowd.

CV = s / x̄

Compare spreads across units. Not for means near 0.

Chebyshev: at least 1 − 1/k² within k·s; at most 1/k² beyond

Any shape.

Bell: 68% ±1s, 95% ±2s (1.960), 99.7% ±3s; top 5% above x̄ + 1.645s

Only if the shape is a bell.

Lesson 6A · Tests

One sample: t = (x̄ − μ₀) / (s/√n), df = n − 1

One mean against a claim.

Two samples: t = (x̄₁ − x̄₂) / √(s₁²/n₁ + s₂²/n₂), df = n₁ + n₂ − 2

Two independent groups.

Two-sided: reject if |t| > t*. One-sided: t past t* in H1's direction.

Top header one-tail, bottom header two-tail.

Type I = reject a true H0 (α). Type II = miss a false H0 (β). Power = 1 − β.

Lower α → higher β; bigger n lowers both.

Reject if p < α

Software output.

Lesson 6B · Correlation

cov = Σdₓdᵧ / n

Sign only.

r = cov / (sₓ·sᵧ)

Ladder: 0.10 weak, 0.40 medium, 0.70 strong, 0.90 very strong.

var = w²var(x) + (1 − w)²var(y) + 2w(1 − w)cov

Two-asset portfolio.

Lesson 7 · Regression

β̂₁ = Σdₓdᵧ / Σdₓ² = (nΣxy − ΣxΣy) / (nΣx² − (Σx)²) = r·sᵧ/sₓ

Slope.

β̂₀ = ȳ − β̂₁x̄

The line passes through (x̄, ȳ).

e = y − ŷ; Σe = 0

Data minus model.

R² = 1 − Σe² / Σdᵧ² = r²

Share of variation explained.

t = (coefficient − value) / SE, df = n − 2

Printouts. The printed t tests 0.
